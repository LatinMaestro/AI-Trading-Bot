# Definition of done

The project is complete only when:

- all master-plan phases intended for release are closed;
- the system operates autonomously in the approved mode;
- every live-capable credential is proven unable to withdraw or transfer funds;
- all strategy, risk and execution decisions are reproducible and auditable;
- duplicate, stale, partial, rejected and ambiguous order cases are handled safely;
- the bot returns to a safe mode after data, provider, permission or model drift;
- Australian-dollar transaction and tax records can be exported completely;
- infrastructure usage and cost are monitored;
- incident, kill-switch, credential-rotation and recovery runbooks are tested;
- live activation and capital increases retain explicit user gates;
- no documentation promises that US$200 will become US$1,000,000.
